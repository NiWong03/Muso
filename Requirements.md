# Muso: Music Wrapper App


- A youtube api wrapper that embedds videos with background play allowing users to use as a free music app without ads
- Built for native ios


## Functional Requirements

- allows playback for videos/music (playback system)
- save songs/videos into a favorits playlist
- user database for individual users to store personal data like playlists and favorites (login and auth system)
- search bar, allows users to search for videos/music
- saving music
- library
- Queueing system for music (add next, add last, delete, queue persistence)
- *suggestion (caching layer)



## Technical Requirements:
- *Probably utilize swiftUI for IOS native compatibility (I want to fully utilize ios features for smoothest ui and performance)
- *Caching layer to optimize api calls and personalize music
- *Use xcode for native capatibiility and testing, app will mainly be used for personal use, develop for beta use
